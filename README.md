An out-of-office auto-reply written by a houseplant that actually works for a living — or at least, that is what the timesheet says.

> Out of office: I clocked 1,400 hours of photosynthesis this year, and HR still calls it just sitting there.

## How to run

```sh
node main.ts
```

The program writes the auto-reply above to `/output/entry.txt`. No dependencies, no network — Node standard library only. It creates the output folder if it does not exist yet, and writes the text with no trailing newline.

## Result

The entry is exactly 107 characters, inside the competition's 1–120 character gate, with no trailing newline and no extra lines.
